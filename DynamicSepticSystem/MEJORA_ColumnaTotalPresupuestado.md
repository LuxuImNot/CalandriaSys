# MEJORA: Columna "Total Presupuestado" en FormEstimacionConceptoMigrado

## Resumen del Cambio

Se agregó una nueva columna **"Total Presupuestado"** en el TreeListView que muestra el costo total presupuestado de cada partida y concepto, independientemente de si está marcado o completado.

---

## Nueva Columna Agregada

### Columna: Total Presupuestado

**Características:**
- **Ubicación:** Entre "Concepto/Partida" y "Monto"
- **Ancho:** 130 píxeles
- **Alineación:** Derecha
- **Formato:** Moneda con 2 decimales (`{0:C2}`)
- **Ordenable:** No

**Comportamiento:**
- **Para Conceptos:** Suma de todos los totales presupuestados de sus partidas
- **Para Partidas:** Su propio total presupuestado (`nodo.Total`)

## Significado de Cada Columna

### 1. Total Presupuestado (NUEVO)
- **Qué muestra:** El costo TOTAL planificado originalmente
- **Cuándo cambia:** NUNCA (es un valor fijo del presupuesto)
- **Para qué sirve:** Referencia del costo completo de la partida/concepto

### 2. Monto
- **Qué muestra:** 
  - Si está **marcado (checkbox)**: Vista previa del costo total (= Total Presupuestado)
  - Si está **completado**: Monto ejecutado real
  - Si está **desmarcado**: $0.00
- **Cuándo cambia:** Al marcar/desmarcar checkbox o al completar
- **Para qué sirve:** Ver cuánto costará la estimación al marcar partidas

## Implementación Técnica

### AspectGetter de la Columna

```csharp
var colTotalPresupuestado = new OLVColumn("Total Presupuestado", "Total")
{
    Width = 130,
    IsEditable = false,
    TextAlign = HorizontalAlignment.Right,
    AspectToStringFormat = "{0:C2}",
    Sortable = false
};

colTotalPresupuestado.AspectGetter = delegate(object x) {
    var nodo = (NodoConcepto)x;
    if (nodo.EsConcepto)
    {
        // Para conceptos: suma de totales de todas las partidas
        return nodo.Partidas.Sum(p => p.Total);
    }
    else
    {
        // Para partidas: su total presupuestado
        return nodo.Total;
    }
};
```

## Ventajas de la Nueva Columna

### 1. **Transparencia Total**
- El usuario ve siempre el costo completo presupuestado
- No necesita hacer cálculos mentales

### 2. **Comparación Fácil**
- Columna "Total Presupuestado": Costo completo
- Columna "Monto": Costo de lo marcado o ejecutado
- Diferencia visible de inmediato

### 3. **Toma de Decisiones Informada**
- "¿Puedo estimar todas las partidas de este concepto?"
- Mira "Total Presupuestado" ? $320,611.87
- "No, solo marcaré algunas"

### 4. **Auditoría y Control**
- Siempre visible cuánto se presupuestó originalmente
- Facilita detectar desviaciones o sobrecostos

### 5. **Consistencia**
- Valor fijo que no cambia
- Referencia confiable para cálculos
