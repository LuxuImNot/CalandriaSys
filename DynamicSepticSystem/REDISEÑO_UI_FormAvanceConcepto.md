## ?? Características Responsive

### **Anchor y Dock Estratégicos**

#### **Elementos con Dock.Top**
- panelTop (70px fijo)
- panelFiltros (80px fijo)
- panelTotales (100px fijo)
- lblTituloTabla, lblTituloFoto, lblTituloGrafica (40px/35px)
- pictureBoxFotoUltima (200px)

#### **Elementos con Dock.Fill**
- tableLayoutPanelContenido (ocupa todo el espacio restante)
- olvAvanceConceptos (dentro de panelIzquierdo)
- pictureBoxGrafica (dentro de panelDerecho, debajo de la foto)

#### **Elementos con Anchor**
```csharp
progressBarAvance:
  Anchor: Top, Left, Right
  ? Se expande horizontalmente al agrandar la ventana

lblEstadisticas:
  Anchor: Top, Right
  ? Se mantiene pegado a la derecha

olvAvanceConceptos:
  Dock: Fill (dentro de panelIzquierdo)
  ? Se ajusta vertical y horizontalmente

pictureBoxGrafica:
  Dock: Fill
  ? Ocupa todo el espacio restante debajo de la foto
```

### **TableLayoutPanel Responsive**
```csharp
ColumnStyles:
  - Columna 0: 50% (Panel Izquierdo - Tabla)
  - Columna 1: 50% (Panel Derecho - Foto + Gráfica)

RowStyles:
  - Fila 0: 100% (Única fila, se expande vertical)

Comportamiento:
  ? Al agrandar ventana ? Ambos paneles crecen proporcionalmente
  ? Al achicar ventana ? Se mantiene distribución 50-50
  ? Tamaño mínimo: 1000x700 px
  ? Maximizado por defecto
```

## ?? Código de Ejemplo: TableLayoutPanel

```csharp
// TableLayoutPanel de 2 columnas con distribución 50-50
this.tableLayoutPanelContenido.ColumnCount = 2;
this.tableLayoutPanelContenido.ColumnStyles.Add(
    new System.Windows.Forms.ColumnStyle(
        System.Windows.Forms.SizeType.Percent, 50F));
this.tableLayoutPanelContenido.ColumnStyles.Add(
    new System.Windows.Forms.ColumnStyle(
        System.Windows.Forms.SizeType.Percent, 50F));

// 1 fila que ocupa el 100% del alto
this.tableLayoutPanelContenido.RowCount = 1;
this.tableLayoutPanelContenido.RowStyles.Add(
    new System.Windows.Forms.RowStyle(
        System.Windows.Forms.SizeType.Percent, 100F));

// Dock Fill para ocupar todo el espacio disponible
this.tableLayoutPanelContenido.Dock = System.Windows.Forms.DockStyle.Fill;

// Padding de 10px alrededor
this.tableLayoutPanelContenido.Padding = new System.Windows.Forms.Padding(10);
```
