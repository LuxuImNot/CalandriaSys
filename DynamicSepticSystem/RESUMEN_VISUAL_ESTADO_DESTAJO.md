## Validación de PDF - Antes vs Después

### ANTES (Permitía PDF incompleto)
```
GenerarPdf(destajo):
    if destajo.CuadrillaAsignada != null:
        // Se generaba PDF ?
        // PERO: ¿Cuál es el "estado" real del destajo?
        // ¿Estaba realmente "listo"?
        CrearPdf()
```

### DESPUÉS (Solo completo)
```
GenerarPdf(destajo):
    if NOT destajo.DesatajoActivado:
        MessageBox("No está completamente activado")
        return
    
    if destajo.CuadrillaAsignada.IsEmpty():
        MessageBox("Sin cuadrilla")
        return
    
    // Ambas condiciones cumplidas
    CrearPdf()  ?
```
